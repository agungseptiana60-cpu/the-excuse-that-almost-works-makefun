A one-line excuse a gamer texts the boss to skip work in GTA 6 launch week: the home router died mid-update, the engineer can't come till Friday, and the GTA 6 download is stuck at 3% — so he's home all week, watching it crawl. The program in `main.ts` writes that single line (85 characters, 15 words) to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
